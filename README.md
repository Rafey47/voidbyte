# VOIDBYTE

**ENTER THE VOID. BREAK THE CODE.**

VoidByte is an online sci-fi game universe consisting of three games:

- **Neon Rift** – a game where quick reflexes matter the most
- **Zero Sector** – an interactive futuristic game
- **Dark Circuit** – a sci-fi game that tests your memory and reactions with sequences, score, combos, levels, attempts, and a countdown timer

## Features

- Interactive game play in browser
- Game modes
- Game logic using JavaScript
- Scoring system
- Levels
- Timed game play
- Game over and restart
- Sci-fi interface

## Technologies

- HTML
- CSS
- JavaScript
